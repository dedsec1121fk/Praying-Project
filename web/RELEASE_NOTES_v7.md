# v7 release notes

- 1,080 searchable Orthodox/biblical records.
- English and Greek core content for every record.
- Detailed English and Greek knowledge dossier for every record; 54 central records have individually hand-curated extended dossiers.
- Scripture/tradition reference shown for every record; 578 records also have at least one external source/reference URL in the current dataset.
- 1,080 bundled local fallback images so no entry is blank offline.
- 52 verified Wikimedia Commons icon/image mappings with recorded license/credit data and an optional downloader for offline caching.
- Full-screen search + web interface centered on the Orthodox Cross and Holy Trinity.
- Mouse/finger pan, two-finger pinch zoom, wheel/trackpad zoom, double-tap/double-click zoom, keyboard +/- zoom.
- One composited scene transform and small visible-node budget for lower processor/GPU load.
- Empty cyan/source-link artifact removed.
- Works from local file:// for catalog/text/UI/fallback media and from static repository hosting with the same relative assets.
- Original prayer automation protected files preserved byte-for-byte.
